# 복지대상자 안부 확인 관리 프로그램

복지 담당자가 사용하는 복지대상자의 안부 확인 서비스와 1인망 연결망을 관리하는 프로그램입니다.

## 주요 특징

- **100% 오프라인**: 인터넷 연결 없이 로컬에서만 동작
- **SQLite DB**: 모든 데이터는 로컬 파일(`welfare_data.db`)에 저장
- **엑셀 연동**: 엑셀 파일 불러오기/내보내기 지원
- **엑셀 스타일 필터**: 각 열 헤더에서 체크박스 방식 필터링
- **1인망 연결망 관리**: 대상자별 비상연락처/이웃/가족 등 연결망 관리

## 설치 및 실행

### exe 파일 실행 (권장)
`복지대상자_안부확인.exe` 파일을 더블클릭하면 바로 실행됩니다.
별도 설치가 필요 없습니다.

### Python으로 실행
```bash
# 필요 패키지 설치
pip install -r requirements.txt

# 실행
python main.py
```

### 샘플 데이터 생성
프로그램을 처음 사용할 때 테스트용 샘플 데이터를 생성할 수 있습니다.
```bash
python create_sample.py
```

## 시작하기

### 1단계: 데이터 등록
- **엑셀 불러오기**: `Ctrl+O` 또는 "📁 엑셀 불러오기" 버튼 클릭
  - 파일 선택 후 열 매핑 설정 (엑셀 열 → 프로그램 필드)
  - 기존 데이터에 추가 또는 전체 교체 선택
- **직접 입력**: `Ctrl+N` 또는 "➕ 대상자 추가" 버튼 클릭

### 2단계: 연결망 관리
- "1인망 연결망" 탭에서 대상자 선택 후 연결망 인물 추가
- 관계, 역할, 방문주기 등 설정

### 3단계: 안부 확인 기록
- "안부 확인 이력" 탭에서 이력 추가
- 날짜, 확인방법, 결과, 메모 등 기록

### 4단계: 통계 확인
- "통계" 탭에서 담당자별, 서비스별, 연결망 현황 확인

## 주요 기능

### 대상자 관리 (탭 1)
- 대상자 추가/수정/삭제 (CRUD)
- 담당자별 조회 (좌측 패널)
- 엑셀 스타일 열별 필터링 (▼ 버튼 클릭)
- 다중 열 필터 AND 조합
- 통합 검색 (이름, 전화번호, 주소 등)
- 열 헤더 클릭 정렬

### 1인망 연결망 (탭 2)
- 대상자별 연결망 인물 관리
- 관계, 역할, 방문주기 설정
- 연결망 없는 대상자 경고 표시

### 안부 확인 이력 (탭 3)
- 안부 확인 기록 추가/수정/삭제
- 기간별, 결과별 필터 조회
- 이력 엑셀 내보내기

### 통계 (탭 4)
- 담당자별 대상자 현황
- 서비스별 분포
- 돌봄등급별 현황
- 1인망 연결망 현황 (경고 표시)

### 엑셀 내보내기
- 현재 화면 내보내기 (필터 적용)
- 전체 내보내기
- 담당자별 시트 분리 내보내기
- 1인망 연결망 포함 내보내기

## 자주 묻는 질문 (FAQ)

### Q: 엑셀 파일을 불러왔는데 열이 안 맞아요
A: 열 매핑 다이얼로그에서 각 엑셀 열이 어떤 필드에 해당하는지 드롭다운으로 선택해주세요. 예를 들어, 엑셀의 "성명" 열을 프로그램의 "이름" 필드로 매핑합니다. 한 번 설정하면 다음에 같은 형식 파일을 열 때 자동으로 적용됩니다.

### Q: 데이터가 사라졌어요
A: 프로그램 시작 시 자동으로 `welfare_data_backup.db` 백업 파일이 생성됩니다.
이 파일을 `welfare_data.db`로 이름을 바꾸면 이전 데이터를 복원할 수 있습니다.

### Q: 다른 PC에서 쓰고 싶어요
A: exe 파일과 `welfare_data.db` 파일을 함께 복사하면 다른 PC에서도 동일한 데이터로 사용할 수 있습니다.

### Q: 엑셀 필터는 어떻게 쓰나요
A: 테이블의 각 열 헤더를 클릭하면 필터 팝업이 나타납니다. 원하는 값만 체크박스로 선택하고 "적용"을 클릭하세요. 여러 열에 동시에 필터를 걸 수 있으며, 모든 조건은 AND로 조합됩니다.

### Q: 삭제한 대상자를 복구할 수 있나요
A: 삭제 시 실제로 데이터가 삭제되는 것이 아니라 상태가 "삭제됨"으로 변경됩니다(소프트 삭제). DB에 데이터가 남아 있으므로 필요 시 복구 가능합니다.

## 데이터 백업

`welfare_data.db` 파일을 정기적으로 USB나 다른 폴더에 복사해두세요.
이 파일 하나에 모든 데이터(대상자, 연결망, 이력)가 저장되어 있습니다.

## exe 빌드 방법

